# ADR-0014: REST API conventions

- **Status**: Accepted
- **Date**: 2026-11-05
- **Deciders**: Project owner (default)
- **Source**: scoping document §7.4
- **Tags**: backend
- **Related**: ADR-0013, ADR-0015 · **Supersedes**: none

## Context

Many modules expose CRUD and aggregate endpoints. Without conventions, each module invents its own shapes.

## Decision drivers

- Predictable endpoints and errors
- Translatable errors (ADR-0013)
- IDs safe to expose and sortable

## Considered options

1. **REST + JSON with shared conventions below**
2. **GraphQL** — flexible queries, extra tooling, weaker fit with FastAPI's OpenAPI generation

## Decision

- Prefix `/api/v1`; plural kebab-case resources (`/half-days`, `/week-templates`).
- IDs: UUIDv7, generated by the backend.
- Timestamps `created_at`, `updated_at` (UTC, ISO 8601). Calendar dates as `YYYY-MM-DD` without time zone.
- Deletion: entities referenced elsewhere are archived (`archived_at`), not deleted; `DELETE` on them returns `409 ENTITY_REFERENCED` unless archiving is requested.
- Lists: `limit` (default 50, max 200) + `offset`, response `{ items, total }`.
- Errors: `{ "code": "MISSION_NOT_FOUND", "detail": "<English, for logs>", "params": {...} }`, codes in `UPPER_SNAKE_CASE`, one registry in `app/core/errors.py`.
- Validation errors are mapped to the same shape with code `VALIDATION_ERROR` and per-field codes.
- Bulk operations are explicit endpoints (`POST /half-days/bulk`) and transactional (all or nothing).
- Non-blocking business warnings are returned in a `warnings: [{code, params}]` field.

## Rationale

GraphQL brings little for a single client and complicates authorization per field.

## Consequences

- **Positive**: uniform client code, generated types (ADR-0015)
- **Negative**: aggregate views need dedicated endpoints (e.g. mission overview)
- **Follow-ups**: P0-9

## Compliance

Test that every error raised in services is a registered code; OpenAPI schema review.

## Notes

- 2026-11-05 (P0): UUIDv7 is generated by a small in-house implementation (`app/shared/ids.py`, RFC 9562, monotonic within a millisecond) because Python 3.13 has no `uuid.uuid7`; switch to the standard library when moving to Python ≥ 3.14.
