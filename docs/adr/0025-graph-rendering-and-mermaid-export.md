# ADR-0025: React Flow + ELK for graphs, server-side Mermaid export

- **Status**: Accepted
- **Date**: 2026-11-05
- **Deciders**: Project owner (default answers)
- **Source**: initial brief ("schemas exportable as MermaidJS"); Q-H10, Q-H11, Q-H12
- **Tags**: architecture-app
- **Related**: ADR-0022, ADR-0023 · **Supersedes**: none

## Context

Architectures must be explored as an interactive graph (domains nested in parent domains, typed relations) and exported as Mermaid to paste elsewhere.

## Decision drivers

- Interactive editing (drag an edge between two nodes)
- Readable automatic layout with nested groups
- Deterministic, testable Mermaid output

## Considered options

1. **React Flow (`@xyflow/react`) + `elkjs` layout; Mermaid generated by the backend**
2. **Cytoscape.js** — strong graph analytics, less natural for custom React nodes
3. **Render Mermaid only (no interactive graph)** — no in-graph editing, poor at large sizes

## Decision

- Interactive view: React Flow with custom nodes (icon per `kind`, owner, criticality), sub-domains as group nodes, ELK layered layout. Manually moved positions persisted in `DomainLayout(architecture_id, domain_id, x, y)`.
- Relations can be created by dragging between nodes; domains can be created from the graph.
- Mermaid export generated **server-side** in `app/modules/architecture/mermaid.py`: `flowchart` (sub-domains as nested `subgraph`, relations as labelled edges, dashed for ASYNC, shapes per kind) and `mindmap` (domain tree). Options: depth, kinds, direction `LR|TB`, include TARGET lifecycle. Node IDs derived from stable short hashes of UUIDs; labels escaped.
- Mermaid is rendered in the browser with the `mermaid` package for previews and SVG/PNG download.
- C4 export and Mermaid import are out of V1 (P13).

## Rationale

Cytoscape makes rich React nodes awkward. Mermaid-only fails the editing need and becomes unreadable beyond ~50 nodes.

## Consequences

- **Positive**: one generator reused by API, document export and tests
- **Negative**: two renderings (React Flow and Mermaid) can look different
- **Follow-ups**: P9-1 to P9-13

## Compliance

Snapshot tests of Mermaid output; frontend test parsing generated Mermaid with `mermaid.parse`.
